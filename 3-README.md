# APP FCBQ · Arquitectura y funcionamiento

Página pública en español que explica la arquitectura y el uso del proyecto APP FCBQ:

- **APP FCBQ** como biblioteca central de Google Apps Script.
- **Template APP** como proyecto ligero con funciones puente.
- **Google Sheets** como interfaz y almacén de los datos de cada usuario.

## Publicación en GitHub Pages

El sitio es estático y no necesita compilación. GitHub Pages puede publicarlo directamente desde la rama `main` y la raíz `/`.

## Archivos

- `index.html`: estructura y contenido.
- `styles.css`: diseño responsive, sin dependencias externas.

## Privacidad

La página no incluye credenciales, datos personales, identificadores privados ni contenido de las hojas.
